Volumetric Explosions @VERSION@
for Kerbal Space Program 1.12.x

The game's explosions as a simulation of fire, smoke and dust, drawn as a true volume.
It needs no other mod. With BD Armory installed, BD Armory's explosions, fire and smoke are
drawn the same way (Alt-B, or Option-B on a Mac, flips between these and BD Armory's own).

INSTALL
  Copy the folder VolumetricExplosions from this download into your KSP's
  GameData folder, and start the game. To remove the mod, delete that folder.

WHERE IT WORKS
  This version was made and tried on Windows 11, on the game's own Direct3D 11: launches,
  crashes, BD Armory's effects, a nuclear explosion. The mod has a small library of its own
  that does its heaviest sums; in this download it is the one for Windows.

  On a Mac and on Linux (OpenGL) this version has not been tried: the mod does those sums
  with its own code there, slower, and its newest changes to the shaders are not packed for
  OpenGL. Version 0.9.0 is the last one made and tried on a Mac.

SETTINGS
  GameData/VolumetricExplosions/PluginData/settings.cfg
  (Until 0.3.1 it was beside the library, where every change to it made the game's next
  start a slow one. A file found there is moved, with what you had set in it.)

Everything else: https://github.com/IshiakiZ/ksp-volumetric-explosions
